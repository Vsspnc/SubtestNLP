Computer Network Fundamentals

A computer network is a collection of interconnected devices that exchange data and share resources using agreed protocols. An endpoint can be a laptop, phone, server, printer, or sensor. A network link may use copper cable, fiber-optic cable, or radio waves. Protocols define how devices format messages, identify destinations, detect errors, and coordinate communication. The Internet is a global network of networks; it is not a single cable or one central computer.

Networks are often described by their scope. A personal area network connects devices near one person. A local area network (LAN) serves a home, office, or campus. A wide area network (WAN) connects sites across large geographic distances, often through a service provider. The labels describe scale and administration, not a particular speed. A wireless LAN uses radio access points, while a wired LAN commonly uses Ethernet switches and twisted-pair or fiber links.

A message is divided into smaller units for transmission. At different layers these units may be called frames, packets, segments, or datagrams. Each layer adds control information such as addresses and protocol identifiers; this is encapsulation. At the receiver, headers are interpreted and removed in reverse order. A link-layer frame is used on one local link, while an IP packet can be forwarded across multiple networks. The data-link header is normally replaced at each routed hop, but the source and destination IP addresses usually remain the same end-to-end, apart from address translation.

Important performance measures are not interchangeable. Bandwidth is the maximum data rate a link can carry under stated conditions. Throughput is the rate actually achieved by an application. Latency is the time for data to travel between points; round-trip time measures a request and response. Jitter is variation in delay, which can disturb real-time audio or video. Packet loss means some packets do not arrive. Congestion, weak wireless signals, overloaded devices, and faulty links can reduce throughput or increase delay.

Common devices have different responsibilities. A repeater regenerates a signal. A Layer 2 switch learns source MAC addresses and forwards Ethernet frames within a LAN. A router connects IP networks and forwards packets according to a routing table. A wireless access point bridges wireless stations to a LAN. A modem adapts a connection to a provider's access technology. A firewall applies traffic policy; it may be a dedicated device or software. One box sold as a home router may combine routing, switching, wireless access, NAT, DHCP, and firewall functions.

A topology describes how devices and links are arranged. In a star topology, endpoints connect to a central switch or access point; a failed central device can affect many endpoints. A mesh has multiple paths and can improve resilience, but requires more links and planning. Real networks use combinations of topologies. Network design considers capacity, availability, security, cost, physical distance, and the consequences of a component failure.

When diagnosing a connection, proceed from the local link toward the remote service. Check power and link or wireless association, then verify the device's IP address, subnet prefix, default gateway, and DNS settings. Test the gateway before testing a remote address, and compare access by IP with access by hostname to distinguish routing from name-resolution problems. Record the exact error and time. A successful ping does not prove that every application or port is reachable because firewalls may block ICMP while allowing other traffic.
